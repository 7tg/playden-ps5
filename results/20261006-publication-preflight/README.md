# Read-only publication preflight

`PreflightSettingsPublication` is the real read-only filesystem preflight adapter for the coordinator. It validates frozen canonical paths, the borrowed stable publisher descriptor, the exact prior receipt or initial receipt absence, the private data/control/library/prefix tree and owned staged title/game directories. It does not grant OWNER reservation, approved kit/source provenance or stopped-title status; the production producer must supply those independent checks and hold its exclusive lease.

Initial profiles/input trees and descriptor must be absent, even if an existing file contains intended bytes. Existing DXVK requires a previous committed publication binding that same target; an ownership-looking header or matching frozen snapshot alone is insufficient. Updates read the actual previous descriptor and use the pinned shared native verifier for the exact previous receipt and retained metadata digest, including profile/catalog/input/DXVK/registry semantics. A newly referenced profile/input destination must be absent unless the previous metadata owns it. DXVK before presence/bytes/mode and registry before bytes/mode must match their frozen snapshot/backup. Registry edits are rendered read-only before pending publication to catch malformed/duplicate targets early. No publication directory/file is created or modified; verified reads and absence are synced.

Default coordinator tests now use this real preflight. The isolated prior-DXVK effect tests explicitly retain a fixture authorization seam to exercise captured original-mode effects without manufacturing a previous publication; they do not prove initial production ownership. Actual previous-set fixtures exercise the shared native preflight and prove that missing prior files and identical desired bytes in a newly referenced input path do not confer ownership.

The initial link failed on the unimplemented preflight symbol, then passed with implementation. Tests refuse existing initial input trees, identical initial DXVK with no previous ownership, missing prior profile, identical unowned new input, and changed registry backup before journal/pending creation. A separate changed-registry-after-pending test still proves effect-level collision refusal. All 105 host tests pass, as do warning/diff checks and SDK v0.43 archive compilation.

The production OWNER/registration adapters, operation creation under those adapters, completed-journal retirement, installer/UI integration, final native link, independent final Task C review and PS5 acceptance remain unfinished. No console app or runtime was changed.
