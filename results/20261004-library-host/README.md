# Representative library host captures

These 3840 × 2160 captures use the `host-fixtures` preset, the exact checked-in `fixtures/library.json`, and semantic `--keys` controller commands.

- `library.png`: bounded 1,000-record library with long Latin, Greek, and Cyrillic names, a missing-art placeholder, and a visible development-fixture label.
- `details-international.png`: Greek fixture details and the development-only install entry point.
- `confirmation.png`: nested install confirmation with the underlying details route retained.
- `queue-progress.png`: changing synthetic queue at 7%.

The screenshot path disables host swap interval waiting so unattended capture can complete. These images verify layout and state only; they are not performance evidence.
