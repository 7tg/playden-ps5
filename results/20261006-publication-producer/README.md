# Publication operation producer

`SettingsPublicationOwner::Prepare` validates the reserved immutable OWNER/package identity and positively stopped activity, acquires the existing qualified private publisher lock, and either recovers the exact immutable active operation or captures a new operation. A recovered operation preserves its original snapshot/timestamp and refuses changed plan/kit/OWNER intent rather than regenerate files from a newer recipe. New capture uses the actual persisted OWNER state/journal/failure snapshot, with the prospective settings revision.

`CaptureSettingsPublicationOperation` generates descriptor JSON, one-entry catalog and schema-2 completion metadata from the exact supplied plan/record, using pinned profile parsing, canonical Wine working-directory derivation and real byte digests. Registry policy binds executable-specific Version and Desktop LogPixels, with strict string/DWORD/absent kinds and duplicate/unsupported target refusal. It reads/qualifies the actual prior committed complete set under the borrowed lease, captures DXVK presence/bytes/mode and registry original bytes/mode, validates frozen encoding, creates an exclusive immutable registry backup when edits exist, and runs complete read-only preflight before returning the frozen operation. No live settings, publication directories, operation journal, receipt or OWNER state are changed during capture; immutable backup preparation can write.

Prepare requires existing initialized control/lock and independently checked package provenance. An orphan backup before journal creation never grants ownership and is not silently adopted, even if its bytes match. Failure may retain such an orphan. Recovery of an already active frozen operation is implemented; crash-safe handoff of a freshly captured operation before coordinator journal creation, initial control setup and orphan OWNER-intent recovery remain unfinished. Do not treat the returned in-memory operation as a durable job result.

Real durable OWNER tests now use the producer for their initial publication and next revision, then exercise journal archival and native reconciliation. Tests preserve frozen timestamps across fresh repository recovery, refuse changed same-transaction plans, bind generated Version=win10 and LogPixels=0x000000a8 metadata, publish real DXVK renderer header bytes, preserve immutable original registry backup and refuse pre-journal backup adoption. Metadata tests caught and corrected absent-kind initialization: the shared contract's absent enum is 1, not zero. All 105 host tests, warning/diff checks and SDK v0.43 archive compilation pass.

Producer startup/handoff persistence, control/orphan-intent recovery, explicit uncertain-registration recovery, installer/UI routing, final application link, independent Task C review and actual PS5 acceptance remain open. Production guard capability trust remains disabled, the retained Wine runtime is unchanged, and no console app was deployed.
