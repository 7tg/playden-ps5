were removed. No bottle, game title or existing game contents were changed.

The diagnostic binary is developer-only, compiled with Playden's SDK v0.43,
with the exact guard and scalar provider sources. The authored source/binary

`restoration.json` records those hashes. The PS5 was released afterward.

This proves native Playden-context admission and uncontended publisher lock
operation. It does **not** prove concurrent-process exclusion, pending publication

startup, or title-exit release. The SDK v0.42 prospero wrapper remains a separate
acceptance target. Production guarded kit trust stays disabled.
