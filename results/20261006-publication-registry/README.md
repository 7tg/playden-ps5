# Pending registry publication

`ApplyPendingPublicationRegistry` is the production registry-effect adapter for the journaled publisher. It requires the exact valid frozen operation and durable pending receipt, validates the borrowed descriptor against the stable owned private lock, reloads the immutable backup and renders owned edits with the frozen timestamp. The caller remains responsible for exclusive lock ownership and positively stopped native activity; the helper never acquires/converts the borrowed lock.

The live `user.reg` must be an owned single-link regular file in the private bottle. It accepts only the captured original bytes/mode or already applied intended bytes in mode 0600. It rejects changed live content during pending recovery rather than overwrite it. It writes through the existing durable Storage implementation (exclusive temporary file, file fsync, checked rename, parent fsync), reads back the exact intended bytes, and retains the backup and pending evidence on failure. Unrelated registry entries in the captured backup are preserved. No fixed backup or immediate rollback is used. Complete committed native admission continues to compare owned registry values semantically; this pending write admission does not change that policy.

Tests run this real registry writer inside the coordinator, with actual immutable backup and pending journal/receipt files. They verify preservation of unrelated values and backup bytes, rejection of changed live bytes, invalid lock and committed receipt refusal, process death after registry publication before profile creation, deterministic retry, and an actual RLIMIT_FSIZE write fault followed by successful recovery. The latter leaves the original registry untouched before rename; failed temporary files remain for explicit reconciliation.

The full host suite passes 105/105. After adding unrelated-registry preservation to the fixture, the focused coordinator test also passes. Warning checks and diff checks pass. SDK v0.43 builds the settings publication static archive. This is not a final native application link or console acceptance.
