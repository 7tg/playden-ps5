# UI polish from the 2026-10-07 console run — plan

Agreed with the user on 2026-10-07. Not implemented yet. Each item lists what was seen and the intended change.

## Details

1. **Focus lands on Cloud saves instead of Play.** When Details opens while the runtime is still checking, Play is
   disabled, so focus skips to the next button and stays there once Play becomes available. Change: while Play is the
   primary action and the player has not moved focus, move focus to Play when it becomes enabled.
2. **Play is much larger than the other buttons.** Play uses the "primary action" style, which is drawn larger, and only
   while it is enabled, so the button also changes size as its state changes. Change: one height for the whole action
   row; Play keeps its accent fill as the primary action but not a larger size, in every state.
3. **Raw step names** (`stage-title`, `copy-template`, `publish-profile`, `await-native`) show in the PS5 title line.
   Change: map each step to player words ("Setting up the game", "Copying the Windows environment", "Applying
   settings", "Waiting for the PS5"), never the identifier.
4. **Progress while preparing and removing.** Show a progress bar on the Play/PS5 title row where a fraction is known:
   the template copy (files or bytes copied of the template's total from the kit manifest) and the trash/bottle deletion
   (entries removed of the counted total). Steps without a measurable fraction show only their words, no bar and no
   spinner percentage.
5. **"Saves from a previous install (size)" is missing** for an uninstalled game; only "Delete saves" shows. Change: the
   status row renders in Details (it is built in the model but not drawn by the Details layout), next to Install.
6. **Kept name carries " (Steam)".** The kept marker stores the PS5 title name. Change: store and show the game's name
   without the store suffix.

## Dialogs and Settings

7. **"Also delete saves and settings" is cut off** in the uninstall dialog. Change: a shorter label ("Delete saves too")
   or a wider button; the dialog body already explains what it deletes.
8. **Focus jumps to the section list after a dialog closes** in Settings when the row it came from disappeared (the kept
   entry, the unused-settings entry). Change: return focus to the nearest remaining row in the same section.
9. **Kept game data becomes one entry that opens a manager.** Settings > Library shows a single "Kept game data" row with
   the count and total size ("2 games · 900 MB"). It opens a modal listing every kept game (name, size, kept date) with a
   checkbox each, "Select all", and "Delete selected" with a confirmation that names how many games and how much space.
   With nothing kept, the row reads "None" and does not open.
